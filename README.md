# Claude skills

Skills for Claude, each with a one-click install.

## Translate (English to Kirundi), version 3.6.1

Translates everyday messages into Kirundi for parents and families, and checks that dates, times,
numbers and contacts came through unchanged.

**Install in the Claude chat:** [open Claude with the install message typed in](https://claude.ai/new?q=Please%20install%20the%20Translate%20skill%20using%20https%3A%2F%2Fraw.githubusercontent.com%2FBFlinkDesign%2Fclaude-skills%2Fmain%2Ftranslate%2FINSTALL.md), then click send.
Claude gives you the file and the three clicks to add it.

**Install in Claude Code:** paste this message and send it. Claude downloads the skill, checks it and installs it.

```
Please install the Translate skill using https://raw.githubusercontent.com/BFlinkDesign/claude-skills/main/translate/INSTALL.md
```

What gets installed is in [`translate/skill`](translate/skill). The packaged file is
[`translate/translate-v3.6.1.zip`](translate/translate-v3.6.1.zip), and its checksum is in
[`translate/SHA256SUMS`](translate/SHA256SUMS).
